Built a wearable, hands-free AI assistant for electronics work at the YC x Moss Conversational AI Hackathon 2026. Integrated a Raspberry Pi with smart glasses featuring a USB camera, microphone, and SSD1306 OLED display for real-time agent-state feedback. Implemented on-device wake word detection using openWakeWord (ONNX), live streaming speech-to-text via LiveKit/Deepgram, and vision grounding through Qwen3-VL-Flash to identify electronic components on a workbench. Used Moss for sub-10ms semantic retrieval from datasheet PDFs and MiniMax-M3 for grounded, streaming reasoning with rolling conversation memory. Built a ROS-style node graph with asyncio for parallel vision, STT, and TTS pipelines achieving ~3s end-to-end latency. Won 2nd Place competing against Ivy League graduates, industry professionals, and technical founders as a high school sophomore.
